# プライバシーポリシー

このプライバシーポリシーは、当サイト (recorder.appcloud.info) と Chrome 拡張機能 (Instant Tab Recorder) におけるユーザーデータの取り扱いについてご理解いただくことを目的としております。

ユーザーのプライバシー保護を第一に考え、不必要にデータを取得、保持、提供いたしません。

なお、本サービスの利用条件については [利用規約](TERMS_JA.md) をご確認ください。

## 取得する情報

Chrome 拡張機能は、アクセス解析、クラッシュレポート、利用統計の収集を行いません。追跡用のユーザー ID も生成しません。

録画データ (映像、音声) および文字起こしテキストは端末内で処理され、拡張機能によってアップロードされることはありません。録画データは、ご自身でエクスポートまたは削除するまでブラウザのローカルストレージに保存されます。

拡張機能の設定は Chrome の storage に保存されます。拡張機能の Chrome Sync を有効にしている場合、同期対象の設定は Google アカウントを通じて Chrome が同期します。これは Chrome の機能であり、Google のプライバシーポリシーに従います。

文字起こし機能にオプトインすると、拡張機能は Hugging Face からモデルデータをダウンロードします。この通信では、IP アドレスなどの接続情報が同サービスに伝わります。録画データや文字起こしテキストはダウンロードのリクエストに含まれません。

## Cookie

拡張機能では直接使用しておりません。外部サービスでは、各サービスのポリシーに従って Cookie が取り扱われる場合があります。

## 利用する外部サービスについて

アクセス解析、クラッシュレポート、利用状況の把握を目的とした外部サービスは利用しておりません。

過去のバージョンでは、クラッシュレポートと利用状況の把握のために [Sentry](https://sentry.io/privacy/) を利用していました。Sentry は Bug Tracking 設定および依存していた Feedback 機能とあわせて削除されました。

- [Hugging Face](https://huggingface.co/privacy)
  - 目的: 文字起こし機能を利用する際に必要なモデルデータの取得に利用しております
  - Chrome 拡張機能 v1.8.0 で追加されました
  - Options Page => Settings からオプトインすることで、モデルデータのダウンロードが行われます
  - 通信時に収集される情報については、同サービスのプライバシーポリシーをご参照ください
